Logarithmic odds scales. At 0% or 100%, markers are clipped to the visual axis limits; numerical results remain exact.

Pre-test odds = p / (1 − p) · Post-test odds = pre-test odds × LR · Post-test probability = odds / (1 + odds)

LR+ = sensitivity / (1 − specificity); LR− = (1 − sensitivity) / specificity. These formulas assume estimates are applicable to the population and context being evaluated. Sequential test updates require accounting for dependence between tests.

Use limitation: Educational/research calculator, not validated as a clinical decision system. It does not set treatment thresholds or provide medical recommendations. All calculations run in your browser; there are no network requests or stored patient data.
